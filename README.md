# 簡単な計算器

四則演算ができるシンプルな計算器です。Web版とPython CLI版の2つのバージョンがあります。

## Web版（推奨）

ブラウザで動作するインタラクティブな計算器です。

### 機能

- 四則演算（加算、減算、乗算、除算）
- 美しいグラデーションUIデザイン
- 計算履歴の表示（最大10件）
- キーボードショートカット対応
- レスポンシブデザイン（スマートフォン対応）
- エラー処理（0による除算）

### 使い方

1. ブラウザで `index.html` を開く
2. ボタンをクリックまたはキーボードで数値と演算子を入力
3. `=` または `Enter` キーで計算実行

### キーボードショートカット

- `0-9`, `.`: 数値入力
- `+`, `-`, `*`, `/`: 演算子
- `Enter` または `=`: 計算実行
- `Esc` または `C`: クリア
- `Backspace`: 最後の文字を削除

## Python CLI版

コマンドラインで動作する対話型計算器です。

### 機能

- 四則演算（加算、減算、乗算、除算）
- エラー処理（0による除算、無効な入力）
- 日本語メニュー

### 使い方

```bash
python3 calculator.py
```

または実行権限を付与して直接実行:

```bash
chmod +x calculator.py
./calculator.py
```

### 使用例

プログラムを実行すると、メニューが表示されます:

```
========================================
簡単な計算器
========================================

操作を選択してください:
1. 加算 (+)
2. 減算 (-)
3. 乗算 (*)
4. 除算 (/)
5. 終了

選択 (1-5):
```

操作を選択し、2つの数値を入力すると計算結果が表示されます。

# 簡単な計算器

Pythonで作成したシンプルな四則演算計算器です。

## 機能

- 加算 (+)
- 減算 (-)
- 乗算 (*)
- 除算 (/)
- エラー処理（0による除算、無効な入力）

## 使い方

```bash
python3 calculator.py
```

または実行権限を付与して直接実行:

```bash
chmod +x calculator.py
./calculator.py
```

## 使用例

プログラムを実行すると、メニューが表示されます:

```
========================================
簡単な計算器
========================================

操作を選択してください:
1. 加算 (+)
2. 減算 (-)
3. 乗算 (*)
4. 除算 (/)
5. 終了

選択 (1-5):
```

操作を選択し、2つの数値を入力すると計算結果が表示されます。

## 要件

- Python 3.x
